# Formularz bez Firebase Cloud Functions

Wariant z Firebase Functions nie jest już częścią wdrożenia. Nie włączaj planu Blaze ani Cloud Build. Aktualna instrukcja konfiguracji poczty i ręcznego wdrożenia: [formularz na Spark](docs/formularz-kontaktowy/SPARK.md).

Ten plik zachowano jako odsyłacz dla starych instrukcji. Brak aktywnych Functions w konfiguracji Hosting nie dowodzi, że w projekcie chmurowym nie ma dawnych zasobów. Niczego nie usuwaj automatycznie.
